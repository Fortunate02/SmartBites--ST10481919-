# SmartBite Food Delivery Website (Part 2)

## Project Overview
SmartBite is a modern food delivery platform connecting customers, restaurants, and delivery drivers via a user-friendly web and mobile interface.  
This part focuses on **CSS Styling, Responsive Design, and Interactive Features**, ensuring the website looks polished and functions well on all devices.

---

## Features Implemented in Part 2

- **External CSS**: All pages linked to `styles.css`.
- **Base Styling**: Default fonts, colors, margins, and paddings applied.
- **Typography**: Readable headings, paragraphs, and gradient text for a luxury feel.
- **Layout**: Flexbox and CSS Grid used for structuring hero section, cards, and footer.
- **Animations**: Hover effects, floating animations, and fade-ins for interactivity.
- **Visual Styles**: Gradient backgrounds, shadows, and premium card design.
- **Responsive Design**:
  - Mobile-first design approach.
  - Breakpoints for mobile (≤320px), tablet (≤768px), and desktop (≥1024px).
  - Font sizes, grids, and navigation adjusted for each breakpoint.
- **Navigation**: Hamburger menu for mobile; horizontal menu for desktop.
- **Interactive Features**:
  - Enquiry form with JavaScript validation and feedback messages.
  - Dynamic restaurant listing updates.
  - Lightbox gallery for featured dishes.
  - Interactive Google map in About Us page.
  - Search functionality for restaurants.
